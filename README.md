# Hermes 🪽

Your own AI agent, running on your computer — with a little web chat page to
talk to it. This is the starting point for the workshop. Get it running as-is
first, then we'll use an AI coding IDE to add your own features.

Unlike a bot that just forwards messages to a company's servers, **Hermes runs
on your machine** and remembers what you talk about. This web app is a friendly
face in front of it.

---

## Before the workshop (do this at home!)

The install is the one slow part, so please do it **before** you arrive — on
venue wifi with everyone at once it's painful. It only takes a few minutes at home.

### 1. Install Node.js and Git

- [Node.js](https://nodejs.org) (the "LTS" version)
- [Git](https://git-scm.com)

### 2. Install Hermes

**Mac / Linux:**
```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```
Then reload your terminal: `source ~/.bashrc`  (or `source ~/.zshrc`)

**Windows (PowerShell):**
```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

### 3. Check it works

```bash
hermes doctor
```
This checks the install, not the web chat yet. Continue below and get a real
reply in your browser before marking your setup complete.

> You don't need to pick a model by hand — `npm run setup` (next section) turns
> on a **free, no-sign-up** model for you. At the workshop we'll switch to a
> faster OpenAI model together, using a key we share.

## Before the workshop: get the web app running

Once Hermes is installed, this part is quick.

The starter repository is private. Sign into GitHub and accept your workshop
invitation before cloning. If you see a 404, ask a facilitator for access.
On Windows, use `npm.cmd` wherever the commands below say `npm`.

```bash
# 1. Get the code
git clone https://github.com/amaanr/hermes-bot.git
cd hermes-bot

# 2. Install the web app's pieces
npm install

# 3. Connect the web app to your Hermes (one time)
npm run setup
```

Keep this terminal open for Hermes. Open a **second** terminal for the web app.
In the second terminal, type `cd ` (with a space), drag your `hermes-bot` folder
into the window, and press Enter. Both terminals should be inside that folder.

```bash
# Terminal 1 — start your Hermes agent (leave this running)
hermes gateway

# Terminal 2 — start the web app
npm run dev
```

`npm run dev` also checks the setup automatically. If you started the gateway
before setup finished, stop it with **Ctrl+C** in Terminal 1 and run
`hermes gateway` again so it reads the new settings.

Open **http://localhost:3000** and send **"Reply only with: Hermes is ready."**
A real reply means you're ready; the welcome message alone doesn't count.

> **Two different keys:** `API_SERVER_KEY` is a local connection password
> generated by setup. It is not an OpenAI key and costs nothing. The free
> at-home model needs no model-provider account or API key. At the workshop,
> add the shared `OPENAI_API_KEY` to Hermes, not in place of `API_SERVER_KEY`.

> If the page shows a **"Waiting for Hermes…"** bar, it just means Terminal 1
> isn't ready yet. `hermes gateway` can print warnings about optional tools
> you haven't connected. You don't need to wait for a particular log message;
> leave it running and the bar clears itself. If it stays after a minute or
> the gateway exits with an error, check the guide's Help desk. No reload needed.

> **First reply feels slow?** The free models are shared and their speed varies.
> If yours is sluggish or errors, switch to another free one — no restart of the
> web app needed. In a third terminal, run:
> ```bash
> hermes config set model.default mimo-v2.5-free
> ```
> Then restart `hermes gateway` in Terminal 1 with Ctrl+C followed by
> `hermes gateway` and send another message. Run `hermes model` to see the
> current list. Free-model availability and response times can change.

## Switching to OpenAI (at the workshop)

When we hand out the OpenAI key, add it to Hermes and pick the model:

```bash
hermes model      # choose OpenAI, paste the key we give you
```

Choose **OpenAI API** (not a ChatGPT/Codex subscription), then the model named
by the instructors. Restart `hermes gateway` with Ctrl+C followed by
`hermes gateway`. Leave the web app running and send another test message.

You **don't** need to change any code — the web app just asks Hermes for a
reply, and Hermes uses whatever model you picked.

## What's inside

| File | What it does |
| --- | --- |
| `SOUL.md` | Hermes's personality. **Edit this first!** |
| `server.js` | The web app's backend. Passes your messages to your local Hermes. |
| `setup.mjs` | One-time setup that connects the web app to Hermes. |
| `public/index.html` | The chat page you see in the browser. |
| `public/style.css` | The colors and layout. |
| `public/app.js` | Sends your messages to the server. |
| `.env` | Local settings (created by `npm run setup`). |
